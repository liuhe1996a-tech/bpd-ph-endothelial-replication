# Source data for the JGG submission

This archive contains the numerical source tables underlying Figures 1–5 and
Supplementary Figures S1–S4 of the manuscript:

> **Cross-cohort single-cell genomics of neonatal hyperoxia reveals reproducible endothelial responses and cohort-dependent model rankings**

Release: `v1.0.0-jgg`  
Archival DOI: https://doi.org/10.5281/zenodo.22263929

The directory names follow the final JGG figure numbering. Figure 3 contains the
external mouse meta-replication panels, Figure 4 contains the two-cohort
perturbation-prediction benchmark, and Figure 5 contains the primary LungMAP human
transfer analysis. Supplementary Figure S3 contains the network-prioritization
tables, and Supplementary Figure S4 contains the technically confounded four-donor
projection tables.

The archive changes no numerical result from the checksum-audited frozen analysis.
Full derived data, model outputs, analysis seeds and restoration checksums are
provided separately in `Supplementary_Data_JGG.zip` and
`Supplementary_Software_JGG.zip`.
