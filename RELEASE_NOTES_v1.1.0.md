# v1.1.0-bib-submission

Submission release for **Simple baselines match variational autoencoders in a cross-dataset neonatal lung endothelial benchmark**.

Changes from v1.0.0-submission:

- adds the held-out age-by-hyperoxia linear, PCA, VAE and conditional-VAE benchmark;
- adds paired animal-level bootstrap comparisons and independent capillary calibration;
- adds CollecTRI regulon, p53 perturbation and animal-balanced ligand-receptor analyses;
- adds a unified dry-run/execution entry point (`run_bib_workflow.py`);
- updates the README to match the Briefings in Bioinformatics case-study manuscript.
